# 🌱 AgroSphere AI – AI-Powered Precision Agriculture Platform

## Overview

**AgroSphere AI** is an intelligent agriculture platform that leverages **Machine Learning** and **Deep Learning** to assist farmers, researchers, and agricultural professionals in making data-driven decisions. The platform provides smart recommendations for crop selection, fertilizer optimization, and plant disease diagnosis, helping improve productivity, sustainability, and resource utilization.

---

## Problem Statement

Agriculture remains the backbone of many economies, yet farmers often face challenges related to crop selection, soil nutrient management, and disease identification. Incorrect decisions can lead to reduced yields, excessive fertilizer usage, and financial losses.

AgroSphere AI addresses these challenges by providing intelligent recommendations powered by advanced AI models.

---

## Key Features

### 🌾 Crop Recommendation System

Analyzes soil nutrients and environmental parameters to recommend the most suitable crop for cultivation.

**Inputs:**

* Nitrogen (N)
* Phosphorus (P)
* Potassium (K)
* Temperature
* Humidity
* Rainfall
* Soil Conditions

**Output:**

* Recommended crop with optimal growth potential.

---

### 🧪 Fertilizer Optimization System

Evaluates soil nutrient composition and crop requirements to determine nutrient deficiencies or excesses.

**Inputs:**

* Soil Nutrient Values
* Crop Type
* Temperature
* Humidity
* Moisture

**Output:**

* Recommended fertilizer strategy for improved crop health and yield.

---

### 🍃 Plant Disease Detection System

Uses Deep Learning-based image classification to identify plant diseases from uploaded leaf images.

**Capabilities:**

* Disease Identification
* Disease Description
* Prevention Measures
* Treatment Suggestions

**Output:**

* Predicted disease with actionable recommendations.

## Installation

### Clone Repository

```bash
git clone <repository-url>

```

### Install Frontend Dependencies

```bash
cd croprecommender
npm install
npm start
```

### Run Backend APIs

```bash
cd ML_MODEL/API
python app.py
```
